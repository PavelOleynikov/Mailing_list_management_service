# Веб-приложение для рассылки сообщений

Веб-приложение на Django, которое позволяет пользователям управлять рассылками сообщений для клиентов. 
Приложение включает функциональность для создания, просмотра, редактирования и удаления рассылок, а также отправки сообщений по требованию.

## Основные функции

1. Управление клиентами
- Добавление новых получателей рассылки
- Просмотр списка клиентов
- Редактирование существующих клиентов
- Удаление клиентов

2. Управление сообщениями
- Создание шаблонов сообщений
- Просмотр списка сообщений
- Редактирование сообщений
- Удаление сообщений

3. Управление рассылками
- Создание новых рассылок
- Просмотр списка рассылок
- Редактирование параметров рассылки
- Удаление рассылок
- Ручной запуск рассылки

### Реализовано:
1. Система аутентификации
2. Регистрация с подтверждением email
3. Вход/выход из системы
4. Общее количество отправленных сообщений

#### СТЭК
1. Backend: Django
2. Frontend: HTML5, CSS, JavaScript, Bootstrap
3. База данных: PostgreSQL
4. Кеширование: Redis

##### Установка и запуск

    Клонировать репозиторий:
    - git clone https://github.com/PavelOleynikov/Mailing_list_management_service
    - cd Mailing_list_management_service
    - python manage.py migrate

После запуска сервера вы можете получить доступ к системе через веб-интерфейс по адресу http://localhost:8000.
